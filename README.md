# sstryujin.pro — личный сайт Владимира

Сайт-визитка, одна страница. Собран из исходников в `~/Documents/Проекты/feniks-site`
(Next.js, TypeScript, Tailwind CSS, Framer Motion) и экспортирован как статика
(`output: "export"`) — в этом репозитории лежит только собранный результат,
исходный код сюда не переносится.

## Деплой

GitHub Pages, ветка `main`, корень репозитория. Кастомный домен — через файл
`CNAME` (`sstryujin.pro`). DNS домена — в панели hoster.by, A-записи указывают
на IP GitHub Pages, `www` — CNAME на `sstruyjin.github.io`. `.nojekyll`
обязателен — без него GitHub Pages ломает папку `_next/`.

Любой пуш в `main` обновляет сайт за 1-2 минуты.

Чтобы обновить сайт после правок в исходниках:

```bash
cd ~/Documents/Проекты/feniks-site
npm run build
cp -r out/. ~/Documents/Codex/sstruyjin-pro/
cd ~/Documents/Codex/sstruyjin-pro
git add -A && git commit -m "..." && git push
```

Источник правды по содержанию (кейсы, формулировки, что можно/нельзя
заявлять) — Obsidian-вейлт Владимира, не этот репозиторий:

  система позиционирования (вердикт, кейсы, формулировки, семантическое ядро).
- `~/Documents/Сферы/Личное/Феникс — бренд и продукт (план)/06_PITCH_AND_RESUME_DRAFT.md`
  — безопасные формулировки по кейсам.
- `~/Documents/Сферы/Личное/Профиль — Карьера и кейсы.md` — доказательная
  карта карьеры.

Перед тем как менять кейсы или формулировки — сверяться с этими файлами, не
выдумывать цифры/результаты.

## История решения (2026-10-01)

До этой версии сайт был одним статичным HTML-файлом с японским минимализмом
(ма, тонкая линия, один акцент-печать) — осознанное решение от 2026-09-28,
сделанное в параллельной сессии. Владимир явно попросил заменить его на
Next.js-версию с другой визуальной концепцией (тёмная индиго-тема, авторская
SVG-схема контура управления вместо фото) — замена сознательная, не случайная
перезапись. Если решение пересматривается — обновить и этот раздел.
